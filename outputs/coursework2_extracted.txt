1.3 Model Evaluation (12 points)
Comprehensive evaluation using multiple metrics:
1.3.1 Regression Metrics (if predicting continuous values)
MAE (Mean Absolute Error): Average error magnitude
RMSE (Root Mean Squared Error): Penalizes large errors
R² (R-squared): Proportion of variance explained
MAPE (Mean Absolute Percentage Error): Relative error (optional)
1.3.2 Classification Metrics (if predicting categories)
Accuracy: Overall correctness
Precision: True positives / predicted positives
Recall (Sensitivity): True positives / actual positives
F1 Score: Harmonic mean of precision and recall
ROC-AUC: Area under ROC curve
1.3.3 Time Series Metrics (if forecasting)
MAE, RMSE as above
MAPE for relative error
Forecast skill: Compare to naive baseline (e.g., tomorrow = today)
1.3.4 Cross-Validation
K-fold cross-validation (k=5 or 10)
Report mean and std of metrics across folds
Assess model stability
1.3.5 Error Analysis
Error distribution: Plot residuals/prediction errors
Worst predictions: Analyze cases where model performs poorly
Systematic errors: Look for patterns in errors (by time, by category)
Confidence intervals: Quantify prediction uncertainty
Deliverable:
Comprehensive evaluation table comparing models
Visualizations:
Actual vs Predicted scatter plot
Error distribution histogram
Time series of predictions vs actual (if applicable)
