# IOT106TC Big Data Analytics — Assignment 1
## Smart Factory Predictive Maintenance: EDA Report

---

## Project Overview

This project performs a full Exploratory Data Analysis (EDA) on the NASA C-MAPSS Turbofan Engine Degradation Simulation dataset (FD001 subset). The analysis covers data quality assessment, RUL (Remaining Useful Life) calculation, feature engineering, sensor screening, and business insight generation for a predictive maintenance context.

**Module:** IOT106TC Big Data Analytics  
**Assignment:** Assignment 1 — Exploratory Data Analysis Report  
**Scenario:** Scenario 1 — Smart Factory Predictive Maintenance  

---

## REQUIRED: Download Raw Data Before Running

The raw data is **not included** in this repository. You must download it manually.

### Step 1: Download the NASA C-MAPSS Dataset

**Option A — NASA PCOE Repository (official):**  
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/  
Download: *Turbofan Engine Degradation Simulation Data Set*

**Option B — Kaggle (convenient mirror):**  
https://www.kaggle.com/datasets/behrad3d/nasa-cmaps  
Download: `CMAPSSData.zip`

### Step 2: Place the File

After downloading, extract and place the file at:

```
data/raw/train_FD001.txt
```

You may optionally also place:
```
data/raw/test_FD001.txt
data/raw/RUL_FD001.txt
```

These are used for Assignment 2 model evaluation but are not required for Assignment 1.

### Step 3: Verify

The file `train_FD001.txt` should be a whitespace-separated text file with no header.  
It contains approximately 20,630 rows and 26 columns.

## How to Run

### Install dependencies

```bash
pip install -r requirements.txt
```

### Launch the notebook

```bash
jupyter lab notebooks/Assignment1_SmartFactory_EDA.ipynb
```

Or with classic Notebook:

```bash
jupyter notebook notebooks/Assignment1_SmartFactory_EDA.ipynb
```

**Run all cells from top to bottom.** The notebook will:
1. Load and validate the raw data
2. Perform data quality assessment
3. Calculate RUL and engineer features
4. Generate all figures (saved to `figures/`)
5. Save the cleaned dataset to `data/processed/SmartFactory_cleaned.csv`
6. Export all summary tables to `outputs/`

### Export the coursework PDF report

Requires `pip install markdown playwright`, then Chromium (run once):

```bash
python -m playwright install chromium
python scripts/build_assignment_report_pdf.py
```

This reads `reports/Assignment1_SmartFactory_Report.md`, embeds Figures 1–10, and writes `reports/Assignment1_SmartFactory_Report.pdf` (about 11 A4 pages in the current styling).

## Important Notes

- **Review before submission:** Read the Markdown/PDF alongside the notebook outputs to confirm citations, tone, and module-specific submission rules.
- **No data fabrication:** The notebook will raise an error if `train_FD001.txt` is not found. All analysis is derived from the real dataset.
- **Outlier handling:** Extreme late-life sensor values are preserved, as they may represent valid degradation signals.
